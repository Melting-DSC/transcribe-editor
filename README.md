# 文字起こしエディタ

音声を聴きながら、文字起こしデータを手早く整文・校正するための、ブラウザだけで
動く編集ツールです。CSV / TSV の読み込みと書き出しに対応し、話者のまとめ直しや
タイムスタンプの修正を GUI で行えます。

インストール後はローカルで完結して動作し、**サーバーも API キーも不要**です。
編集内容が外部に送信されることはありません。

- **できること** — 既存の文字起こしデータの編集・整文、話者の整理、CSV/JSON/テキスト出力
- **できないこと** — 音声から文字起こしテキストを自動生成する（音声認識）機能

> このアプリはあくまで「編集ツール」です。音声→テキストの変換は別途ご用意ください。
> 生成済みのテキストを CSV などで読み込むか、手入力してご利用ください。

---

## 主な機能

- **発言ごとの編集** — 本文・タイムスタンプ・話者名をその場で修正
- **音声との同期** — ローカルの音声ファイルを添付し、再生位置に合わせて発言をハイライト表示
- **CSV / TSV インポート** — ファイル選択・ドラッグ＆ドロップ・テキスト貼り付けに対応
- **書き出し** — CSV / JSON / テキスト（台本形式）で保存、クリップボードへのコピーも可能
- **話者の一括管理** — 話者名の一括置換と、同一人物の名寄せ（統合）
- **検索・絞り込み** — 発言内容の検索、話者での絞り込み
- **Undo / Redo** — 編集の取り消し・やり直し
- **自動保存** — 編集中のデータはブラウザに自動保存され、リロードしても復元

## 動作環境

- Node.js（インストールと起動に使用）
- モダンなブラウザ（Chrome / Edge / Safari / Firefox の最新版を推奨）

## インストールと起動

```sh
# 1. 依存関係をインストール
npm install

# 2. 開発サーバーを起動
npm run dev
```

ターミナルに表示された URL（通常 `http://localhost:5173`）をブラウザで開きます。

配布用にビルドして確認したい場合:

```sh
npm run build     # dist/ に本番ビルドを出力
npm run preview   # ビルド済み dist/ をローカルでプレビュー
```

### 公開版（GitHub Pages）

インストールせずにブラウザだけで試したい場合は、公開版を利用できます。

**https://melting-dsc.github.io/transcribe-editor/**

`main` ブランチに push すると GitHub Actions が自動でビルド・公開します
（`.github/workflows/deploy.yml`）。公開ページ用のビルドは base パスを付けるため
`npm run build:pages` を使います（ローカルの `npm run build` は `/` のままです）。

## 基本的な使い方

### 1. 文字起こしデータを読み込む

上部ヘッダーまたはツールバーの **「CSVインポート」** から取り込みます。

- **ファイルから選択** — `.csv` / `.tsv` / `.txt` を選ぶか、ドラッグ＆ドロップ
- **テキストを貼り付け** — Excel などの表からコピーしたテキストをそのまま貼り付け
- **取り込み方法** — 「上書きインポート」または「末尾に追記マージ」を選択
- **対応する音声ファイルを紐付け（任意）** — 同じ画面で音声を添付すると、取り込み後すぐ再生できます

読み込み前にプレビューが表示されるので、内容を確認してから取り込めます。

> 動作を試したいだけの場合は、ツールバーの **「デモ読み込み」** からサンプルデータを
> 読み込めます（音声も一緒に読み込まれます）。

### 2. 音声を添付する

ツールバーの **「音声インポート」**、または画面下部プレーヤーの **「音声を差し替え」**
から音声ファイルを選択します。文字起こしデータを変えずに音声だけを差し替えられます。

添付すると下部にプレーヤーが表示され、再生位置に合わせて該当の発言がハイライトされます。

### 3. 発言を編集する

各発言カードで次の操作ができます。

- **本文** — テキスト欄を直接編集
- **タイムスタンプ** — 値をクリックするとその位置から再生。鉛筆アイコンで手入力に切り替え
- **話者** — 話者バッジをクリックして一覧から選択、または新しい話者名を入力して追加
- **カード右上のボタン**
  - ✂️ カーソル位置で分割
  - 🔀 下の発言と結合
  - ➕ 下に新しい発言を追加
  - 🗑️ この発言を削除（最後の1件は削除できません）

ツールバーの **「発言追加」** で末尾に発言を追加できます。

### 4. 話者をまとめて整理する

ツールバーの **「話者を一括編集」**（またはヘッダーの「話者一括管理」）を開きます。

- **一括置換** — 話者名を入力して「一括置換」。プリセット候補も利用可能
- **統合** — 「統合元」と「統合先」を選んで、別名で検出された同一人物を名寄せ

### 5. 検索・絞り込み

ツールバーの検索ボックスに文字を入力すると、本文・話者名で絞り込まれます。
話者ドロップダウンで特定の話者の発言だけを表示できます。

### 6. 書き出す

- ツールバーの **「CSVダウンロード」** — CSV 形式で保存
- ツールバーの **「その他の形式で保存」**（下向き矢印）
  - CSV をクリップボードにコピー
  - JSON 形式で保存
  - 台本テキスト（`.txt`）で保存
- **CSVプレビュー** — 書き出す前にテーブル／生テキストで内容を確認し、ファイル名も指定可能

ファイル名は、音声を添付している場合はそのファイル名をもとに生成されます
（例: `meeting.mp3` → `meeting.csv`）。音声がない場合は `transcription.csv` になります。

### 7. 初期状態に戻す

ツールバー右下の **「初期データに戻す」** で、編集内容を破棄してデモデータに戻せます
（確認ダイアログが表示されます）。

## 音声プレーヤーの操作

画面下部のバーで操作します。

| 操作 | 説明 |
| --- | --- |
| ▶︎ / ⏸ | 再生 / 一時停止 |
| ⏪ / ⏩ | 5秒戻る / 5秒進む |
| 速度 | 0.5x〜2.0x から選択 |
| 自動追従 | 再生中の発言に自動でスクロール |
| 🔊 | 音量・ミュート |
| 音声を差し替え | 文字起こしを保ったまま音声だけ変更 |

---

## キーボードショートカット

入力欄（テキスト・タイムスタンプなど）にカーソルがあるときは無効です。

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` | 5秒戻る |
| `→` | 5秒進む |
| `<` または `,` | 再生速度を1段階遅く |
| `>` または `.` | 再生速度を1段階速く |

---

## データ形式

CSV の列は `id,timestamp,speaker,text` です。

```csv
id,timestamp,speaker,text
1,00:00 - 00:05,佐藤,本日はお時間をいただきありがとうございます。
2,00:06 - 00:11,高橋,こちらこそよろしくお願いいたします。
```

- **タイムスタンプ** — `MM:SS`、`HH:MM:SS`、`MM:SS - MM:SS`（範囲）などの自由な文字列に対応
- **文字コード** — UTF-8 / Shift-JIS を自動判定。うまく判定されない場合は
  インポート画面で手動指定できます
- **区切り文字** — カンマとタブ（TSV）を自動判定
- **ヘッダー** — 日本語ヘッダーにも対応（`番号`, `タイムスタンプ`, `話者`, `発言内容` など）。
  ヘッダーがない場合は列数から自動で割り当てます
- **書き出し** — CSV は Excel での文字化けを防ぐため UTF-8 BOM 付きで保存されます

## データの保存と取り扱い

- 編集内容はブラウザの **localStorage** に自動保存され、リロードしても復元されます。
  保存時刻はツールバーに表示されます。
- **音声ファイルは保存されません**（ブラウザの制約）。リロード後は「前回使用した音声は
  再読み込みされていません」という案内が表示されるので、必要に応じて音声を選び直してください。
  CSV 出力時のファイル名には、前回の音声ファイル名が引き続き使われます。
- すべての処理はブラウザ内で完結し、データが外部に送信されることはありません。

## 困ったときは

| 症状 | 対処 |
| --- | --- |
| リロード後に音声が再生されない | ブラウザの制約です。プレーヤーの「音声を差し替え」から音声を選び直してください |
| CSV の日本語が文字化けする | インポート画面の「文字コード設定」で `Shift-JIS` または `UTF-8` を手動指定してください |
| 発言が表示されない | 検索キーワードや話者フィルターが効いていないか確認してください |
| 編集内容が消えた | 「初期データに戻す」を実行したか、ブラウザのサイトデータを消去していないか確認してください |
